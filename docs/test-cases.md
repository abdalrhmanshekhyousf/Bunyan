# حالات الاختبار (T10.4)

خمس حالات تغطي المسارات الأساسية في Data Analytics: الحساب، والمشروع، والخصوصية، والتحليل الذكي، وصلاحيات المدير. تُنفَّذ آلياً على Firebase الحقيقي بالأمر:

```bash
# السيرفر يعمل على 5199
ADMIN_EMAIL=... ADMIN_PASSWORD=... node scripts/test-cases.mjs tc-out
```

ينشئ السكربت مستخدمَين تجريبيين (أ وب) في متصفحين منفصلين، ويحفظ لقطة لكل حالة ونتائجها في `tc-out/results.json`، ثم يحذف كل ما أنشأه.

## TC-01: إنشاء حساب وتسجيل الدخول

|                       |                                                                                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **الهدف**             | التحقق من التسجيل والدخول والخروج وحماية الصفحات                                                                                                                                       |
| **المتطلبات المسبقة** | لا شيء                                                                                                                                                                                 |
| **الخطوات**           | 1. إنشاء حساب بالاسم والبريد وكلمة المرور. 2. تسجيل الخروج. 3. الدخول بكلمة مرور خاطئة. 4. الدخول بالبيانات الصحيحة. 5. فتح `/dashboard` في متصفح لم يسجّل الدخول                       |
| **النتيجة المتوقعة**  | 1. الانتقال إلى «مشاريعي» مع حالة فارغة. 2. رسالة «سُجّل خروجك.». 3. رسالة «البريد الإلكتروني أو كلمة المرور غير صحيحة.» دون دخول. 4. الانتقال إلى «مشاريعي». 5. التحويل إلى صفحة الدخول |

## TC-02: إنشاء مشروع وحفظ الوصف تلقائياً

|                       |                                                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **الهدف**             | التحقق من إنشاء المشروع، والحفظ التلقائي، ومنع تحليل وصف قصير                                                                               |
| **المتطلبات المسبقة** | مستخدم مسجّل الدخول                                                                                                                          |
| **الخطوات**           | 1. إنشاء مشروع بعنوان فقط. 2. ملاحظة زر «حلّل الوصف». 3. كتابة وصف مثال المكتبة (527 حرفاً) ثم إعادة تحميل الصفحة. 4. ملاحظة زر التحليل مجدداً |
| **النتيجة المتوقعة**  | 1. فتح مساحة عمل المشروع. 2. الزر معطّل لأن الوصف أقل من 40 حرفاً. 3. ظهور «تم الحفظ»، وبقاء الوصف كاملاً بعد إعادة التحميل. 4. الزر مفعّل      |

## TC-03: خصوصية المشروع والمشاركة للقراءة فقط

|                       |                                                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **الهدف**             | التحقق من أن المشروع الخاص لا يراه غير مالكه، وأن رابط المشاركة لا يسمح بالتعديل                                                                 |
| **المتطلبات المسبقة** | مشروع للمستخدم أ، ومستخدم ثانٍ ب                                                                                                                  |
| **الخطوات**           | 1. يفتح ب رابط المشروع `/projects/{id}`. 2. يفعّل أ رابط المشاركة. 3. يفتح ب رابط المشاركة                                                        |
| **النتيجة المتوقعة**  | 1. رسالة «لا يمكن فتح هذا المشروع». 2. ظهور الرابط `/share/{id}`. 3. يرى ب المشروع بشارة «قراءة فقط»، والوصف غير قابل للتعديل، ولا يظهر زر الحذف |

## TC-04: التحليل الذكي

|                       |                                                                                                                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

|                       |                                                                                                                                                  |

| **الخطوات**           | 1. يفتح المستخدم العادي لوحة مشاريعه. 2. يفتح `/admin` مباشرة. 3. يدخل المدير ويفتح «لوحة المدير». 4. يبحث المدير ببريد المستخدم ب               |
| **النتيجة المتوقعة**  | 1. لا يظهر رابط «لوحة المدير». 2. يُعاد إلى «مشاريعي». 3. تظهر الإحصاءات الأربع بأرقام، وجدول يضم المستخدمين التجريبيين. 4. يبقى في الجدول ب وحده |
