# نتائج تجارب العربي (T0.8 + T0.9)

التاريخ: 2026-11-19 · Mermaid 12.3 · jsPDF 4.2 · html2canvas-pro 2.6 · Chromium (Playwright)

صفحة التجارب: `npm run dev` ثم افتح `/lab.html`. فحص آلي مع صور وملفات PDF:
`node scripts/lab-check.mjs <مجلد-الإخراج>` (السيرفر على المنفذ 5199).

## T0.8 — Mermaid بالعربي

جُرّب كل مخطط بطريقتين: **A** معرّفات عربية مباشرة، و**B** معرّفات إنجليزية مع تسميات عربية.

| المخطط | A (معرّفات عربية) | B (إنجليزي + تسمية عربية) | ملاحظات |
| --- | --- | --- | --- |
| Use Case (flowchart) | ✅ | ✅ | `flowchart RL` يضع الفاعلين على اليمين |
| Class | ✅ | ✅ | الصياغة: `class Student["طالب"] { ... }` |
| Sequence | ✅ | ✅ | الصياغة: `participant S as الطالب`. الفاعل الأول يظهر يساراً (لا يوجد RTL) |
| Activity (flowchart) | ✅ | ✅ | التفاف النص الطويل يعمل |
| ER | ✅ | ✅ بشرط | التسمية **داخل تعريف الكيان فقط**: `STUDENT["طالب"] { ... }`. وضعها في سطر العلاقة يعطي Parse error |

### مشاكل وحلول

1. **انقلاب النص الإنجليزي داخل صفحة RTL** (ظهر `id: int+` بدل `+id: int`).
   الحل: `unicode-bidi: plaintext` على عناصر نص المخطط (`.mermaid-host` في `index.css`).
2. **قص آخر حرف من النص العربي**: Mermaid يقيس العربي أضيق بـ 2–4px.
   الحل: `.mermaid-host foreignObject { overflow: visible }`.
3. **قياس قبل تحميل الخط**: يجب انتظار `document.fonts.load('16px "Readex Pro"')` قبل `mermaid.render`.
4. **التطويل (ـ) يختفي** في تسميات العلاقات (`يقوم بـ` تظهر `يقوم ب`). تعليمات Gemini يجب أن تمنع التطويل.

### القرار

**الطريقة B**: معرّفات إنجليزية (`^[A-Za-z_][A-Za-z0-9_]*$` كما في T4.16) مع تسميات عربية.
السبب: نفس المعرّفات تصلح لأسماء جداول SQL وأعمدتها، وتمنع مشاكل الصياغة، والعرض للمستخدم عربي بالكامل.
لذلك يجب أن يعيد التحليل لكل كيان وصفة اسمين: `name` (إنجليزي) و`label` (عربي).

## T0.9 — تصدير PDF عربي

| | html2canvas + jsPDF | طباعة المتصفح (`window.print`) |
| --- | --- | --- |
| الحجم (صفحة + مخطط) | 590 KB | 103 KB |
| النص | صورة، غير قابل للتحديد أو البحث | نص حقيقي |
| خط المخطط | يرجع لخط افتراضي أصغر | Readex Pro |
| نقاط القوائم في RTL | تظهر يساراً (خطأ) | يميناً (صحيح) |
| تقسيم الصفحات | يقص الصورة في أي مكان | يحترم `break-inside` |
| تجربة المستخدم | تنزيل مباشر بضغطة | نافذة طباعة ← "حفظ كـ PDF" |

**ملاحظة مهمة:** `html2canvas` الأصلي (1.4.1) **لا يعمل مع Tailwind v4** لأنه لا يدعم ألوان `oklch`
(خطأ: `unsupported color function "oklch"`). البديل المتوافق: `html2canvas-pro`.

### القرار

**طباعة المتصفح هي الطريقة الأساسية** مع CSS للطباعة (`@media print`)، وhtml2canvas-pro + jsPDF احتياطي فقط.
هذا يعكس ترتيب T7.4 / T7.5 في الخطة.
